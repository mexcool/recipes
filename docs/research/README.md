# Research notes

Background research produced while planning the app (November 2026). Each file was written by a research
agent with web access and ends with "Key findings", "Load-bearing claims" (with confidence) and "Open questions".

Caveats:
- The research environment's network policy blocked direct fetches of several sites (retailers, SINU,
  some dietitian sites, several vendor pages). Where a file says a claim was "verified", that often means
  confirmed from search-engine excerpts of the named page, not from opening it. Treat numbers as indicative.
- Price comparison was dropped from the product scope mid-way; `sanremo-prices.md` was re-focused on
  which stores exist in Sanremo and which pack sizes products come in.
- The files refer to the household member on the plan as "G.".

| File | What it covers |
|---|---|
| `planmymeals.md` | PlanMyMeals (Portugal): features, household mechanics, how prices are obtained, monetisation, traction claims |
| `macro-planners.md` | Eat This Much, Macrostax, RP Diet Coach, Fitia, Melarossa, Italian zone-diet apps; why none fit an exchange-based plan |
| `recipe-managers.md` | Paprika, Plan to Eat, Samsung Food, AnyList, Bring!, Tandoor, Mealie, Grocy; reusable data models and libraries |
| `diet-model.md` | How Italian dietitians express "schema a grammature" plans; generic equivalence tables; raw/cooked yields |
| `nutrition-data.md` | CREA, IEO BDA, USDA FoodData Central, Swiss FCDB, Open Food Facts, commercial APIs: coverage and licences |
| `sanremo-prices.md` | Supermarkets in Sanremo, online catalogues, pack sizes of plan items, store section order |
| `tech-stack.md` | SvelteKit/Next/Expo, PWA on iOS 26, Supabase/Cloudflare/D1/local-first, Claude models and pricing, testing |
